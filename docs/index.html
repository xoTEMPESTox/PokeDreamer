PokéDreamer

Dreams the game. Learns to walk in the dream. Plays for real.

A world model (a diffusion network) learned to imagine Pokémon Red one screen at a time from recorded play. Ten navigation skills were trained only inside that imagination, never in the real game, and then carried an agent to the first gym badge in the real game in 30 of 30 runs, 14 of them with no fallback to map-reading navigation (battles are played by rules). The game's own memory is the ground truth that measures, in tiles and maps, where the dream is right and where it drifts.

Summary

In 30 seconds

  • • A world model of a real game. A diffusion model learned to predict Pokémon Red frame by frame from recorded play: you press a button, it imagines the next screen.
  • • An agent that learned inside the dream. Ten navigation skills were trained purely in that imagination, with zero real-game steps, then dropped into the real game, where the agent wins the Boulder Badge in 30/30 runs.
  • • Measured, not eyeballed. The game's own memory says exactly where the agent and the imagined world really are, so every claim below is a number: where the dream drifts, which shortcuts the agent learned to exploit, and why battles can't be learned this way.
  • • Seen in colour. A neural upscaler and colorizer turn the 72x80 greyscale frames into full-resolution colour for display (99.27% per-pixel accuracy on held-out frames).
Overview

What is PokéDreamer?

PokéDreamer is a research project on world models for game agents - teaching an agent to imagine Pokémon Red, train skills inside that imagination, and measure where the dream matches the emulator's memory.

🧠

World Model

A neural network that learns the game's dynamics: given recent frames and a button press, predict the next frame. v1 and v2 predict in a compressed latent space; v3 is a diffusion model that imagines the pixels directly.

🎮

Imagination-Based Training

Instead of stepping the emulator, the agent practises inside the world model. v3's navigation policies were trained only on imagined rollouts, then tested zero-shot in the real game.

📡

Lineage

v1 and v2 follow Hafner et al.'s Dreamer (a recurrent state-space model with discrete latents); v3 follows DIAMOND (Alonso et al., 2024), a diffusion world model.

🔬

Measured Against RAM

The emulator's memory gives ground truth for every imagined frame (map, tile, battle state), so every claim is a number on held-out episodes, compared with simple baselines.

The Research Journey

From symbolic state probes to pixel-level imagination - three generations of world models.

VAE + GRU MPC Planner

The first world model - a Variational Autoencoder compressing frames to 32-dim latents, with a GRU dynamics model predicting the next latent. An MPC planner imagines action sequences and picks the best path using linear probes for map position.

Diffusion World Model + Dream-Trained Agent

A DIAMOND-style diffusion world model of Pokémon Red, and an agent whose navigation was learned entirely inside it. Ten navigation skills trained in imagination carry the agent to the Boulder Badge in the real game in 30 of 30 runs; battles and goal choice are rules, and six local LLMs were tested as the planner. Whether battles can also be trained inside the world model was measured: not with this model. It is left as future work.

v3 diffusion world model: EDM-preconditioned denoiser (lab/dwm/model.py)
    def raw(self, x_noisy, sigma, ctx, actions, aug_bucket):
        """Network output F and EDM scalings; x_noisy (B,1,H,W), sigma (B,), ctx (B,CTX,H,W), actions (B,CTX)."""
        s = sigma[:, None, None, None]
        c_in = 1 / (s ** 2 + SIGMA_DATA ** 2).sqrt()
        c_skip = SIGMA_DATA ** 2 / (s ** 2 + SIGMA_DATA ** 2)
        c_out = s * SIGMA_DATA / (s ** 2 + SIGMA_DATA ** 2).sqrt()
        cond = self.noise_emb(sigma.log() / 4) + self.act_emb(actions).flatten(1) + self.aug_emb(aug_bucket)
        out = self.unet(torch.cat([x_noisy * c_in, ctx], 1), self.cond_mlp(cond))
        return out, c_skip, c_out

📈 v1: Scheduled Sampling vs. Teacher Forcing - Rollout Drift

Measured over 15,536 held-out trajectories of length 29 steps. Scheduled sampling (SS) is critical: the SS model's compounding drift stays roughly flat (3.71–4.38 tiles) out to 29 imagined steps, while the pure teacher-forcing (TF) ablation reaches 11.63 tiles - a 2.7× degradation.

Architecture

v1 vs v2 Architecture Comparison

How the world model evolved across versions - from continuous latents and teacher forcing to discrete RSSM with KL-balancing.

Component v1 (VAE + GRU) v2 (Discrete RSSM)
Resolution 40×36 pixels (PWhiddy downsampled) 160×144 pixels (native Game Boy)
Encoder Variational Autoencoder (VAE) 4-layer Residual CNN → 512-dim embed
Latent Space Continuous R³² (reparameterization) Discrete 32×32 categorical (1024-dim)
Dynamics Autoregressive GRU (scheduled sampling) RSSM: GRU h_t (512) + Stochastic s_t
Gradient Estimator Reparameterization trick Gumbel-Softmax straight-through
KL Balancing Standard ELBO 80% prior / 20% posterior balancing
Imagination Prior-only rollout Full posterior + prior with KL balancing
Decoders Pixel decoder only Pixel + Reward predictor + Continue predictor
Controller Lookahead MPC planner (coordinate probe) Actor-Critic trained in imagination
Get Started

Quick Start Guide

Get PokéDreamer running in minutes. You'll need a legally-obtained Pokémon Red ROM.

01

Clone & Install

bash 
git clone https://github.com/xoTEMPESTox/PokeDreamer.git
cd PokeDreamer
conda env create -f environment.yml
conda activate pokemon-rl
02

Place ROM & Collect Data

Copy your legally-obtained Pokemon - Red Version (USA, Europe).gb to the project root. Alternatively, download the pre-collected dataset from Hugging Face.

bash 
# Collect data (optional - dataset available on HF)
python legacy/v2/scripts/collect_data.py --episodes 20 --out-dir data
03

Train the RSSM World Model

bash 
python legacy/v2/scripts/train_rssm.py \
    --data-dir data \
    --epochs 12 \
    --batch-size 64 \
    --out-dir legacy/v2/checkpoints/rssm_v2
04

Generate Imagination Demo

Renders a side-by-side video comparing the real emulator vs. the RSSM's imagined frames.

bash 
python legacy/v2/scripts/generate_demo_video_v2.py \
    --checkpoint legacy/v2/checkpoints/rssm_v2/best_world_model.pt \
    --save-state saves/intro_done.state \
    --out-video legacy/v2/checkpoints/rssm_v2/side_by_side_demo_v2.mp4
